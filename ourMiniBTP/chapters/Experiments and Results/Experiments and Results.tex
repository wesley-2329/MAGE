\subsection{Metrics Formulations}
The performance is evaluated using standard classification metrics, defined mathematically as follows:
\begin{itemize}
    \item \textbf{Accuracy:} The proportion of correct predictions:
    $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$
    \item \textbf{Precision:} The proportion of positive predictions that are correct:
    $$\text{Precision} = \frac{TP}{TP + FP}$$
    \item \textbf{Recall:} The proportion of actual positive samples detected:
    $$\text{Recall} = \frac{TP}{TP + FN}$$
    \item \textbf{F1-Score:} The harmonic mean of precision and recall:
    $$\text{F1-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$
\end{itemize}
Where $TP$, $TN$, $FP$, and $FN$ represent True Positives, True Negatives, False Positives, and False Negatives, respectively.

\section{Baseline Detection Paradigms}\label{Chapter-3-Paradigms}
We compare four distinct detection paradigms to analyze their relative strengths:
\begin{enumerate}
    \item \textbf{FastText (Lexical):} Matches word and character n-gram frequencies \cite{joulin2016bag}. It is extremely fast but blind to contextual changes, sentence syntax, and word ordering.
    \item \textbf{GLTR (Predictability):} Measures word probability ranks under a reference language model (GPT-2) \cite{gehrmann2019gltr}. It relies on the observation that language models write predictable words (top ranks), whereas humans write with higher entropy.
    \item \textbf{DetectGPT-lite (Zero-Shot Curvature):} Perturbs the text using DistilRoBERTa-base to replace words with synonyms, and measures the change in log-likelihood under GPT-2 \cite{mitchell2023detectgpt}. It requires no training but is computationally intensive.
    \item \textbf{DistilBERT (Contextual):} Processes text bidirectionally to capture subtle stylistic footprints \cite{sanh2019distilbert}. It provides the strongest baseline performance but is vulnerable to OOD shifts.
\end{enumerate}

\section{Proposed Open-Set Rejection Layer}\label{Chapter-3-Novelty}
\noindent To identify and reject text generated by unseen models, we build a Stage-2 open-set rejection layer based on the distributions of the known classes in the embedding space.

\subsection{Mathematical Formulation}
For each known class $c \in \{0, 1\}$ (GPT and LLaMA), we extract training embeddings $\mathbf{x} \in \mathbb{R}^{768}$ and compute the class centroid:
$$\mu_c = \frac{1}{N_c} \sum_{i=1}^{N_c} \mathbf{x}_i^{(c)}$$
We compute the regularized class covariance matrix to ensure mathematical stability:
$$\Sigma_c = \text{Cov}(X^{(c)}) + 10^{-4} \cdot I_{768}$$
The out-of-distribution (OOD) score of a test embedding $\mathbf{z}$ is defined as the minimum Mahalanobis distance \cite{mahalanobis1936generalized} to known class distributions:
$$D(\mathbf{z}) = \min_{c \in \{0, 1\}} \sqrt{(\mathbf{z} - \mu_c)^T \Sigma_c^{-1} (\mathbf{z} - \mu_c)}$$
The OOD threshold $\tau$ is chosen as the **95th percentile** of the known validation set's minimum Mahalanobis distances:
$$\text{Prediction} = \begin{cases} \text{Known } (c) & \text{if } D(\mathbf{z}) \le \tau \\ \text{UNKNOWN} & \text{if } D(\mathbf{z}) > \tau \end{cases}$$

\section{Baseline Open-Set Rejection Results}\label{Chapter-3-Baseline}
In our baseline configuration (unseen: OPT, known: GPT + LLaMA, representation: CLS, distance: Mahalanobis):
\begin{itemize}
    \item \textbf{Selected Threshold ($\tau$):} $63.5972$
    \item \textbf{OPT Unknown Rejection Rate:} $7.59\%$ (608 / 8,012 OPT samples flagged)
    \item \textbf{Known Class False Rejection:} $3.90\%$ (39 / 1,000 test samples incorrectly flagged)
    \item \textbf{OOD Score AUROC:} $0.6298$
\end{itemize}
The baseline OOD AUROC ($0.6298$) represents modest separation. While it maintains a low false rejection rate, only a small fraction of the unseen OPT family is successfully rejected, indicating that the baseline representation space has significant overlap between LLaMA and OPT.
